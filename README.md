# Библиотечная система

## Описание проекта
Система управления библиотекой предназначена для автоматизации учета книг, читателей, выдачи литературы и управления библиотечным фондом. Проект решает задачи эффективного отслеживания доступности книг, контроля сроков возврата, учета читательской активности и оптимизации процессов бронирования и выдачи литературы.
